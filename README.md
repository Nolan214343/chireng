# 迟刃：断界迷城 下载

[![在苹果浏览器游玩](https://img.shields.io/badge/Safari-%E6%89%93%E5%BC%80%E8%8B%B9%E6%9E%9C%E7%BD%91%E9%A1%B5%E7%89%88-0E75B7?style=for-the-badge&logo=safari&logoColor=white)](https://nolan214343.github.io/chireng/ios/)

> iPhone / iPad：请用 Safari 横屏打开；无需安装，即点即玩。网页端由与 Windows / Android 同一 Unity 工程导出，使用相同的关卡、武器、敌人和玩法代码。

> 首次进入会自动建立游客账号并同步云存档；无需注册。请妥善保存在游戏内显示的恢复码，以便在新设备恢复进度。

这个仓库只用于公开发布 Android 安装包、Windows 64 位压缩包和下载页，不包含游戏工程源码。Windows 版为双人协战测试版：一名玩家建立房间，另一名玩家输入房间码加入；房主负责路线、房门和战利品结算，双方实时同步移动、冲刺与协战斩击。

- 苹果：点击上方 Safari 按钮，或打开 https://nolan214343.github.io/chireng/ios/
- 安卓：在下载页点击“安卓下载”，下载安装 APK。
- Windows：在下载页点击“Windows 64 位协战测试版”，解压后启动 `DelayedBlade.exe`。双方在封面点击“双方协战”即可建房或加入。
