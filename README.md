> iPhone / iPad：请用 Safari 横屏打开；无需安装，即点即玩。网页端由与 Windows / Android 同一 Unity 工程导出，使用相同的关卡、武器、敌人和玩法代码。

> 首次进入会自动建立游客账号并同步云存档；无需注册。请妥善保存在游戏内显示的恢复码，以便在新设备恢复进度。

这个仓库只用于公开发布 Android 安装包、Windows 64 位压缩包和下载页，不包含游戏工程源码。

- 苹果：点击上方 Safari 按钮，或打开 https://nolan214343.github.io/chireng/ios/
- 安卓：在下载页点击“安卓下载”，下载安装 APK。
- Windows：在下载页点击“下载 Windows 64 位版”，解压后启动 `DelayedBlade.exe`。
