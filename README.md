> 网页版：使用支持 WebGL 的现代浏览器横屏打开；无需安装，即点即玩。网页端由与 Windows / Android 同一 Unity 工程导出，使用相同的关卡、武器、敌人和玩法代码。

> 首次进入会自动建立游客账号并同步云存档；无需注册。请妥善保存在游戏内显示的恢复码，以便在新设备恢复进度。

> v1.6.33：锻造设施改为限定地图刷新，只在第 1、3、5 章的第二座地牢中出现，且每张指定地图最多一座；其他地图不会重复刷新。开始新一局时仍会保留已穿戴装备和装备背包；路线、金币、消耗品、祝福、雕像与战斗临时状态会正常重置。云端的“新一局”记录也会保留装备库，换设备后可恢复。Android 左下移动继续使用固定摇杆；网页、Windows 与 Android 均由同一 Unity 工程导出。

这个仓库只用于公开发布 Android 安装包、Windows 64 位压缩包和下载页，不包含游戏工程源码。Windows 与 Android 原生版提供双人协战：一名玩家建立房间后可复制 HTTPS 邀请链接，另一名玩家从链接直接唤起新版游戏并加入；房主负责路线、房门和战利品结算，双方实时同步移动、冲刺与协战斩击。队友倒地后，另一人靠近尸体并持续按住救援 2.75 秒即可将其以 35% 灯火救起；松开、离开范围或受击会中断。两人同时倒地则回到本局第一关。

- 网页版：点击上方“在线游玩”按钮，或打开 https://nolan214343.github.io/chireng/ios/
- 安卓：在下载页点击“安卓下载”，下载安装 v1.6.33 APK。左下为固定移动摇杆，需从摇杆底座内按住拖动；锻造设施只会在指定地图内出现，单图最多一座；新一局会保留已穿戴装备与装备背包，局内临时资源会重置。单人模式用屏幕右侧的角色技能按钮施放主动技能；新版 APK 也支持 `delayedblade://` 协战邀请：从邀请页点“打开迟刃”会自动填入并加入房间；也可在“双方协战”中点房间码框，输入六码后按完成或点“房间码加入”。若微信等内置浏览器拦截唤起，可复制六码房间码后手动加入。
- Windows：在下载页点击“Windows 下载”，下载并解压 v1.6.33 压缩包后启动 `DelayedBlade.exe`。锻造设施只会在指定地图内出现，单图最多一座；开始新一局不会清空旧装备；单人模式按 `K` 施放当前旅者的主动技能；双方在封面点击“双方协战”即可建房或加入。房主可点“复制邀请链接”发送到微信、QQ 等聊天软件。第一次使用邀请链接前，请先正常启动一次新版 Windows 游戏以登记系统邀请入口；收到链接会启动独立游戏窗口加入，因此不会突然覆盖已在进行的单人局。为保证实时同步，协战采用统一的行灯规则。

邀请链接只包含房间码，不包含游客账号、云存档或 WebSocket 凭据。若微信等内置浏览器拦截外部应用唤起，好友可以从邀请页复制六码房间码，再在游戏里手动加入。
